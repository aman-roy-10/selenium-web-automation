# Selenium Web Automation

This project is a Python-based web automation project built using
Selenium WebDriver.

The idea behind the project is simple: automate actions that a user
would normally perform manually on a website. Selenium opens the
browser, interacts with the required elements, performs the given
actions, and completes the process automatically.

The project uses Google Chrome for browser automation and
WebDriver Manager to handle the ChromeDriver setup.

For testing and practice, the project uses the Test Automation
Practice website:

https://testautomationpractice.blogspot.com/

The project is focused on browser-based automation and provides a
basic foundation for understanding how automated tests interact with
real web pages.

## Technologies Used

- Python
- Selenium WebDriver
- WebDriver Manager
- Google Chrome
